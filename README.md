## Мета роботи
Практичне засвоєння методів проєктування та розробки програмного забезпечення з використанням об'єктно-орієнтованого програмування, архітектурних підходів (REST API, SOLID, GRASP) та GoF-шаблонів проєктування.

---

## Основні функції та вимоги системи (Варіант 10)

- [x] **Стрічка новин:** головна сторінка зі свіжими публікаціями, тематичні рубрики (політика, економіка, технології тощо), повнотекстовий пошук та фільтрація за датою/автором.
- [x] **Персоналізація контенту:** налаштування улюблених тем, персоналізована стрічка та рекомендації на основі вподобань/переглядів.
- [x] **Профіль користувача:** збережені статті (читати пізніше), система коментування, оцінки (лайки/дизлайки).
- [x] **Система підписок:** розмежування рівнів доступу (безкоштовний перегляд / платна преміум-підписка без реклами та з ексклюзивним контентом).
- [x] **Система сповіщень:** push-повідомлення про гарячі новини (*Breaking News*), підписка на дайджести та авторів.
- [x] **Панель адміністратора / модератора:** CRUD для публікацій, категорій, керування користувачами та аналітика.
